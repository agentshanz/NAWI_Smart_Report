# Prototype Design Guide

This document outlines the design approach used for the **NAWI SmartReport** prototype. The goal of the interface is to present a simple, guided workflow that helps technicians complete the NAWI model approval testing process with minimal complexity.

## Design Objective

The prototype is designed to demonstrate how a digital workflow can replace manual documentation while keeping the interface clean, consistent, and easy to navigate.

## Visual Style

The interface follows a laboratory-inspired theme using a combination of dark blue and purple accents with a light background to improve readability.

| Element      | Color     |
| ------------ | --------- |
| Primary      | `#17324D` |
| Secondary    | `#6D55A6` |
| Background   | `#F8FAFC` |
| Light Blue   | `#DBEAFE` |
| Light Purple | `#E9E0F7` |
| Success      | `#DFF5EC` |

## Typography

* Bold headings for clear section identification.
* Simple, readable body text.
* Consistent spacing to reduce visual clutter.

## Screen Flow

The prototype follows the same workflow presented in the project documentation.

1. Dashboard
2. Instrument Details
3. Applicable Test Plan
4. Test Result Entry
5. Compliance Verification
6. R 76-2 Report Preview

Each screen focuses on one task before guiding the technician to the next step.

## Key Design Principles

* **Simple Navigation** – Keep actions clear and easy to find.
* **Guided Workflow** – Present each step in a logical sequence.
* **Clear Status Indicators** – Make progress and results easy to understand.
* **Consistent Layout** – Maintain a familiar structure across all screens.
* **Minimal Distraction** – Prioritize important information over decorative elements.

## Prototype Scope

The prototype demonstrates the intended user experience and overall workflow of **NAWI SmartReport**. It focuses on explaining the proposed solution and does not represent the complete software implementation.
