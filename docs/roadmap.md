# Project Roadmap

This roadmap outlines the planned evolution of **NAWI SmartReport** from a UI prototype into a complete digital testing platform for Non-Automatic Weighing Instruments (NAWI).

## Phase 1 — Prototype (Current)

* Interactive Figma prototype
* Dashboard and guided workflow
* Instrument registration
* Test plan visualization
* Compliance preview
* R 76-2 report preview

**Status:** Completed

---

## Phase 2 — Functional Prototype

* Digital test forms
* Automatic calculations
* Compliance checking
* PDF report generation
* Test history

**Status:** Planned

---

## Phase 3 — Advanced Features

* User authentication
* Multi-user laboratory support
* Version-controlled rule management
* Audit trail
* Dashboard analytics

**Status:** Future Scope

---

## Long-Term Vision

Create a reliable digital platform that helps laboratories and technicians complete NAWI model approval testing faster, more accurately, and with standardized documentation based on **OIML R 76**.
