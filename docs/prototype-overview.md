# Prototype Overview

NAWI SmartReport is a UI prototype that demonstrates the proposed workflow for Non-Automatic Weighing Instrument (NAWI) model approval testing based on **OIML R 76**.

## Objective

The prototype illustrates how technicians can complete the testing process through a guided digital workflow instead of relying entirely on manual documentation.

## Prototype Flow

1. Dashboard
2. Instrument Details
3. Applicable Test Plan
4. Test Result Entry
5. Compliance Result
6. Report Preview

## Note

This prototype is intended to demonstrate the user journey and interface concept. It does not represent the complete software implementation.
