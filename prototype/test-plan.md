# Applicable Test Plan

This screen demonstrates how NAWI SmartReport determines the required tests based on the instrument details entered by the technician. Instead of manually searching through OIML R 76, the system presents a clear checklist of the applicable tests.

## Purpose

* Identify the required R-76 tests.
* Display a structured test checklist.
* Guide the technician to the next testing step.

## Example Test Categories

* Performance Tests
* Influence & Environmental Tests
* Electrical Tests
* Endurance & Other Tests

## Expected Action

The technician reviews the generated checklist and selects **Start Testing** to begin recording the test results.
