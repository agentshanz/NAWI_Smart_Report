# Prototype Workflow

This workflow illustrates how **NAWI SmartReport** guides a technician through the model approval testing process based on **OIML R 76**.

## Workflow Steps

### 1. Instrument Details

The technician enters the basic specifications of the weighing instrument.

### 2. R-76 Rule Engine

The system identifies the applicable testing requirements based on the entered instrument details.

### 3. Applicable Test Plan

A structured checklist of required tests is generated for the technician.

### 4. Test Execution

The technician performs the physical tests and records the measurements.

### 5. Calculation Engine

The prototype demonstrates automatic calculation of test results and comparison values.

### 6. Compliance Verification

The entered results are checked against the applicable R 76 requirements.

### 7. Test Record

The completed test information is organized into a structured digital record.

### 8. R 76-2 Report Preview

The technician reviews the standardized report before completing the testing process.
