# NAWI SmartReport – Prototype Design Guide

This document describes the screens included in the interactive Figma prototype and how they demonstrate the proposed solution for NAWI model approval testing.

## Prototype Journey

Dashboard → Instrument Details → Applicable Test Plan → Test Result Entry → Compliance Verification → R 76-2 Report Preview

## Screen Overview

### Dashboard

Provides a quick overview of testing activity and allows the technician to start a new test.

### Instrument Details

Captures the basic specifications of the weighing instrument required to determine the applicable tests.

### Applicable Test Plan

Displays the R 76 test categories selected for the instrument.

### Test Result Entry

Allows the technician to record measurements and observations for each applicable test.

### Compliance Verification

Shows whether the entered results satisfy the applicable R 76 requirements and supports retesting if necessary.

### R 76-2 Report Preview

Displays the final standardized report generated from the completed testing workflow.

## Design Principles

* Clean laboratory-style interface
* Minimal navigation steps
* Guided workflow
* Clear status indicators
* Consistent blue and purple theme

## Prototype Purpose

This prototype is intended to demonstrate the proposed user experience and testing workflow for Smart India Hackathon (SIH) 2026. It focuses on explaining the solution rather than representing the complete software implementation.
