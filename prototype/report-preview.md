# R 76-2 Report Preview

This screen demonstrates the final output of the NAWI SmartReport prototype. After the technician completes the required tests and verifies compliance, the system prepares a standardized **R 76-2** report for review and export.

## Purpose

* Present the completed test summary.
* Display the compliance decision.
* Provide a preview of the final R 76-2 report.

## Report Includes

* Instrument Details
* Applied Tests
* Test Results
* Compliance Status
* Technician Information
* Test Date

## Available Actions

* Preview Report
* Download PDF *(Prototype)*
* Start a New Test

### Prototype Outcome

The prototype demonstrates how manual test documentation can be transformed into a structured digital workflow, reducing paperwork and making the model approval process easier to manage.
