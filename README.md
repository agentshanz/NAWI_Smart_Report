# NAWI SmartReport Prototype

A prototype developed for **Smart India Hackathon (SIH) 2026** to demonstrate a digital workflow for **Non-Automatic Weighing Instrument (NAWI)** model approval testing based on **OIML R 76**.

## Prototype Overview

This prototype demonstrates how technicians can:

* Enter instrument details
* View applicable R-76 tests
* Record test results
* Perform automatic calculations (prototype)
* Check compliance
* Generate a sample R 76-2 report

**Note:** This repository is a UI prototype created to demonstrate the proposed workflow and user experience. It is not the complete production implementation.

## Included Screens

* Dashboard
* Instrument Registration
* Applicable Test Plan
* Test Result Entry
* Compliance Result
* Report Preview

## Workflow

Instrument Details → R-76 Rule Engine → Test Plan → Test Execution → Calculation Engine → Compliance Check → Test Record → R 76-2 Report → Final Report
