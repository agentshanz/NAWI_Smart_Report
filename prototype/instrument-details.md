# Instrument Details

This screen is where the technician begins a new NAWI model approval test by entering the basic details of the weighing instrument. The information entered here is used to determine which OIML R 76 tests apply to the instrument.

## Purpose

* Register a new instrument for testing.
* Capture the required technical specifications.
* Prepare the applicable test plan.

## Information Collected

* Manufacturer
* Model
* Accuracy Class
* Maximum Capacity (Max)
* Minimum Capacity (Min)
* Verification Scale Interval (e)
* Scale Division (d)

## Expected Action

After entering the instrument details, the technician selects **Continue** to generate the applicable test plan.
