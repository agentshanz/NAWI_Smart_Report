# UI Icons

This folder contains the icons used in the **NAWI SmartReport** Figma prototype.

The icons follow a simple, professional style to match the laboratory-inspired interface and maintain consistency across all prototype screens.

## Recommended Icons

| Icon               | Used For          |
| ------------------ | ----------------- |
| `dashboard.svg`    | Dashboard         |
| `new-test.svg`     | Start New Test    |
| `clipboard.svg`    | Test Plan         |
| `table.svg`        | Test Results      |
| `check-circle.svg` | Compliance        |
| `file-report.svg`  | Report Preview    |
| `history.svg`      | Test History      |
| `settings.svg`     | Settings (Future) |

## Style Guidelines

* SVG format for scalability.
* Rounded outline icons.
* Consistent stroke width.
* Dark Blue (`#17324D`) as the primary icon color.
* Purple (`#6D55A6`) for highlighted actions when needed.

These icons are used throughout the prototype to create a clean and consistent user experience.
