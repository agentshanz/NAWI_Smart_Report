# Compliance Verification

This screen demonstrates how NAWI SmartReport reviews the entered test results and compares them with the applicable OIML R 76 requirements. Instead of manually checking every value, the prototype presents a clear compliance summary for the technician.

## Purpose

* Review completed test results.
* Compare measurements with the applicable limits.
* Display the overall test outcome.

## Example Status

* **PASS** – The instrument meets the applicable R 76 requirements.
* **FAIL** – One or more test results require correction or retesting.

## Available Actions

* View Result Summary
* Start Retest (if required)
* Continue to Report Preview
