# Dashboard

The Dashboard is the starting point of the NAWI SmartReport prototype. It provides technicians with a quick overview of ongoing testing activities and allows them to begin a new model approval test.

## Purpose

* View the testing dashboard.
* Start a new test.
* Access reports and test history.
* Monitor recent activity.

## Key Elements

* Technician Dashboard
* Registered Instruments
* Pending Tests
* Reports Generated
* Quick Actions
* Recent Activity
